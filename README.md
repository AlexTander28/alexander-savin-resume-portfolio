# Александр Савин - резюме и портфолио

Самодостаточный русскоязычный HTML-лонгрид для позиции Junior Python / Automation Developer. Откройте `index.html` двойным кликом: сервер, сборка и внешние шрифты не нужны.

## Внутри

- семь открываемых кейсов;
- реальные локальные изображения интерфейсов и портрет;
- навыки, рабочий подход и честно обозначенный junior-уровень;
- печатные стили для PDF;
- изображения и шрифты в папке `assets`.

## Проверяемые факты

Три Python-демо используют синтетические данные. Локально подтверждены: 12 тестов для Excel-отчётов, 12 для Telegram CRM и 14 для ИИ-помощника. Реальные ключи, данные CRM и коммерческие показатели в этот материал не включены.

## Файлы для передачи

- `index.html` - HTML-версия;
- `output/pdf/Alexander-Savin-Resume-Portfolio-final-v6.pdf` - проверенная PDF-версия;
- `output/Alexander-Savin-Resume-Portfolio-final-v6-complete.zip` - архив для передачи или загрузки.
