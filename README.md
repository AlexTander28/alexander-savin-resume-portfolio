# Александр Савин — интерактивное резюме

## Просмотр
Публичная страница: https://alextander28.github.io/alexander-savin-resume-portfolio/
Креативная версия: ?view=creator. Техническая версия: ?view=products.

Локально: запустите `npm start` в этой папке и откройте http://127.0.0.1:4173/. Нужен установленный Node.js; внешних зависимостей нет.

## Содержание
Портрет, два разных каталога, контакты, два PDF-резюме и общая презентация. AI Creator: авторский сайт и 53 уникальные визуальные работы в пяти коллекциях (58 размещений с пятью пересечениями исходных коллекций). Продукты: 16 проектов и демонстраций, начиная с трёх CRM. Локальные оптимизированные превью и шрифты; оригиналы работ открываются на исходном портфолио. Лицензии шрифтов находятся в assets/.

Для hh.ru используйте ссылки на нужный вариант страницы и отдельные изображения из hh-covers. HTML-код в анкету не вставляется. Фото, период и контакты утверждены автором. Образование не включено по его просьбе.

## Ограничения
3D-планировщик представлен сохранёнными экранами локального прототипа; публичной кнопки запуска нет. На СтройПроекте форма демонстрационная, интерьерные изображения сгенерированы. Реальные клиентские показатели не заявляются. Страница не собирает заявки и не подключает аналитику; кнопки контактов открывают email, Telegram и телефон.

Без JavaScript остаются базовая страница, ссылка на авторское портфолио и контакты; доступны оба PDF, интерактивное переключение скрыто с пояснением. Для каталога нужна загрузка через HTTP, а не открытие HTML как локального файла.
